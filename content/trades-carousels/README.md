# Tradie pain-point carousels (4 carousels, 29 slides)
A = plumbers (a1-a8), B = builders (b1-b8), C = day in the life (c1-c7), D = before & after (d1-d6).
1. Fetch one real free-licence stock photo per key in photos.json (Pexels/Unsplash, commercial use OK) -> img/<key>.jpg (>=1600px).
2. python3 build.py   (regenerates trades.html from style.css)
3. node render.js     -> out/<id>.jpg at 2160x2700
Rules: no "AI" anywhere, no prices, no real business names/logos, no postal address or mobile.
